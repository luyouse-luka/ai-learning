##### 已改的代码（`day7_review.py`，教练代改）

```python
import sys                               # ← 新增

if __name__ == "__main__":
    # 用法: python day7_review.py <文本文件路径>
    # 路径写死 = 脚本，路径从命令行来 = 工具。分界线就在这三行。
    if len(sys.argv) < 2:
        print(f"用法: python {Path(__file__).name} <文本文件路径>")
        sys.exit(1)                      # 非 0 退出码 = 告诉调用方"我失败了"，管道/CI 才看得见

    input_path = Path(sys.argv[1])       # sys.argv[0] 是脚本自己，[1] 才是第一个参数
    if not input_path.is_file():         # 先验存在，否则下面 open 抛 FileNotFoundError 带一堆栈
        print(f"文件不存在或不是文件: {input_path}")
        sys.exit(1)

    with open(input_path, "r", encoding="utf-8") as f:
        content = f.read()
    print(f"[输入] {input_path}  {len(content)} 字符")   # ← 加这行是判据，见下
```

**三个点，一个都不是凑数的：**

- **`sys.argv[0]` 是脚本自己**，所以第一个参数是 `[1]`。少了 `len(sys.argv) < 2` 这道守卫，
  不带参数运行就是 `IndexError: list index out of range`——用户看到一坨堆栈，不知道自己少给了什么。
- **`sys.exit(1)`**：`0` = 成功，非 `0` = 失败。`print` 一句然后正常退出，
  在 shell 里 `&&` 会继续往下跑，CI 会判绿。**"打印了错误"不等于"报告了失败"**——
  这又是本周主线那句「没有 A ≠ 有 B」的一张脸。
- **`print(f"[输入] ...")`**：这行不是装饰，是**判据**。没有它，你没法证明它读的是你给的那个文件
  ——正好是追问 C 你答错的那件事（以为跑的是 long.txt，其实一直是 short.txt）。
