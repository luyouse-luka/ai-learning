## 当前瓶颈（教练盯的四条，Week 3 结转）

1. **知道了没调用**（第 8 次）—— 答案就在自己写过的文件里，不翻。判据：做决定时那个文件有没有被打开过
2. **静默 bug 意识** —— 「没有 A ≠ 有 B」四张脸：没报错≠有结果 / 判据没变红≠功能对 / 函数写了≠被调用 / 参数传了≠生效
3. **变量作用域·生命周期**（第 5 次）—— 问「谁在维护它」不够，必须再问「**它活多久**」：函数返回就没了？进程退出就没了？
